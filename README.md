# 四十年厄尔尼诺

一张表。一行是一个冬季、海洋上的一个格子。

`data/厄尔尼诺.csv` 共 117600 行。陆地没有海温，不收录。

| 字段 | 说明 |
| --- | --- |
| 冬季 | 北半球冬季，写成 1986/87。年份按 1 月所在的公历年 |
| 纬度 | 格子中心，北纬为正，南纬为负，单位度 |
| 经度 | 格子中心，东经为正，西经为负，单位度 |
| 海温距平 | 该格这一冬的海表温度减去 1991–2020 年同季平均，单位 °C，保留一位小数 |
| 冬季指数 | 这一冬的 NOAA Oceanic Niño Index，单位 °C。同一冬季每一行相同 |

资料是 NOAA NCEI ERSST v5，先算 12 月、1 月、2 月平均，再相对 1991–2020 年同季做距平，然后平均到约 4° 的格子。冬季指数来自 CPC ONI。四十个冬季从 1986/87 到 2025/26。

2015/16 冬季指数是 +2.50。地图方框里的格子平均是 +2.4，和指数一致。
